# Launch the herdr Interactive Application

Opens the local herdr graphical user interface (GUI) in your default web
browser. This allows you to run impact assessments offline keeping your
data private.

## Usage

``` r
run_herdr_app()

run_app()
```

## Value

Invisibly returns the Shiny application output when the session closes.

## Examples

``` r
if (FALSE) { # \dontrun{
run_herdr_app()
} # }
```
