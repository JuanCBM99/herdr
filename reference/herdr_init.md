# Initialize herdr project folders and example data

This function creates the 'user_data' and 'Examples' folders in your
current working directory and populates them with the default files from
the package.

## Usage

``` r
herdr_init()
```

## Value

Invisibly returns `NULL` after creating `user_data/` and `Examples/` in
the working directory.

## Examples

``` r
if (FALSE) { # \dontrun{
herdr_init()
} # }
```
